# Sample template fonts

The Swift package includes the following unmodified TrueType files under the SIL Open Font License 1.1.

- **Inter 4.1** includes Black, Bold, ExtraBold, Medium, and SemiBold. The files are from `extras/ttf/` in
  `Inter-4.1.zip`. [Upstream release](https://github.com/rsms/inter/releases/tag/v4.1) · [License](Inter-OFL.txt)
- **Playfair Display 1.203** includes Black, Bold Italic, and Regular.
  [Pinned upstream files](https://github.com/aaronbell/Playfair-Display/tree/e9c6c4f96e929d6b39cf13d8349816c4424e4254/fonts/ttf) ·
  [License](PlayfairDisplay-OFL.txt)
- **Space Mono 1.003** includes Bold.
  [Pinned upstream file](https://github.com/googlefonts/spacemono/blob/329858c2c4dbd3476f972a4ae00624b018cf4b81/fonts/ttf/SpaceMono-Bold.ttf) ·
  [License](SpaceMono-OFL.txt)
