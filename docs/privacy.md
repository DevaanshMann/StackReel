# StackReel privacy policy

Last updated November 22, 2026

StackReel collects no data about the reels you edit. The iOS editor previews and exports your reel on your device without sending us your clips, music, captions, or editing activity. You don’t need a StackReel account. This policy covers the current iOS development build.

## Media and drafts

You choose which videos to import from Photos or Files and which music to import from Files. If a file is stored in the cloud, its provider may download it to your device. For a template draft, StackReel saves copies of that media along with the draft name, captions, trims, and framing in the app’s storage. Single-clip imports use temporary storage. Depending on your settings, device backups can include drafts and their media.

To remove a draft, open **Projects**, tap **Delete** beside the draft, and confirm. StackReel removes the saved edits and cleans up the draft’s media copies. If cleanup is interrupted, some files may remain in app storage. Deleting a draft leaves your originals, other drafts, previous backups, and any exports you saved or shared intact.

## Exports and sharing

Exporting creates a temporary MP4. StackReel checks for old exports to remove when the app starts fresh. **Save to Photos** requests permission to add the video to your library. If you use iCloud Photos, Apple may sync that copy. **Share MP4** opens the iOS share sheet. The app or service you choose can receive and keep the video.

## Development builds

The Expo launcher loads StackReel from a development server, which can be your computer or one run by someone else. It sends that server an ID for the app installation and can automatically send debugging details, such as an error message and which code was running when a crash occurred.

The server saves the installation ID. To list recent development sessions, it can send Expo that ID, the project name, the server address, and the host computer’s name. Expo’s command-line tool on the developer’s computer also sends usage statistics by default. Developers can turn those statistics off. [Expo CLI telemetry](https://docs.expo.dev/more/expo-cli/#telemetry)

## Crash reports

StackReel has no crash-reporting service of its own. If we add one, it will be off by default and will send reports only if you turn it on. You can manage Apple’s separate device analytics in iOS Settings under **Privacy & Security → Analytics & Improvements**. [Apple’s device analytics and privacy](https://www.apple.com/legal/privacy/data/en/device-analytics/)

## Contact

You can ask general privacy questions in our public issue tracker. Please leave personal details, private media, and diagnostic logs out of your post. [StackReel’s GitHub Issues](https://github.com/DevaanshMann/StackReel/issues)
