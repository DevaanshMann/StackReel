# @stackreel/core

Platform-independent TypeScript logic:

- Timeline resolution: turns a template plus the user's clips into a flat, ordered render plan
- Time math (integer microseconds), snapping, and clip trimming and fitting
- Undo/redo command stack
- Project persistence format

Holds no UI code and no platform media APIs. Not set up yet. See **Phase 1** in the [root README](../../README.md).
